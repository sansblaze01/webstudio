# WEBSTUDIO FR — Luxe sombre

## Mise en ligne sur GitHub Pages

1. Crée un dépôt GitHub (par exemple `webstudio-fr`).
2. Décompresse ce dossier ZIP sur ton ordinateur.
3. Envoie **le contenu de ce dossier** dans la racine du dépôt : `index.html`, `style.css`, les autres pages et `.nojekyll`.
4. Dans GitHub : **Settings → Pages**.
5. Dans **Build and deployment**, choisis **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`, puis **Save**.
6. Attends la publication, puis ouvre l'URL indiquée dans la section Pages.
